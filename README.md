# Проект *"Ядро интернет-магазина"*

## Описание:

Проект *"Ядро интернет-магазина"* даёт возможность реализовать любой интерфейс — от сайта до телеграм-бота

## Где найти:

Репозиторий с проектом находится по адресу  [Github/E-commerce](https://github.com/AmirGadzhimirzaev/E-commerce.git)

## Что внутри:

### Модули:

1. **[templates.py](src/templates.py)** - Содержит классы для описания товара и группы товаров
